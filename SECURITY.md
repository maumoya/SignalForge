# Security

Report vulnerabilities privately through GitHub's Security tab when private reporting is enabled, or contact the maintainer without posting exploit details publicly.

The offline engine never connects to networks, executes discovered content or handles authentication. All external text is untrusted; examples and reports must contain public or synthetic data only. No auto-install, no agent permission bypass, no cookie access. URL validation is syntactic, not a security proof for hypothetical future collectors.

See `skills/signalforge/references/security.md` for threat boundaries.
